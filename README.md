# دفتر من — داشبورد مدیریت کار

داشبورد فارسی و راست‌چین برای مدیریت کارها، پروژه‌ها، تقویم، مشتریان، مالی و اهداف؛ همراه با بانک ۴۰۷ قابلیت و نمای جداگانه نقش‌های شرکت، فریلنس، تدریس و شخصی.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا آن را با GitHub Pages منتشر کنید. این نسخه به نصب وابستگی یا سرور نیاز ندارد.

## داده‌ها
اطلاعات در localStorage مرورگر هر بازدیدکننده ذخیره می‌شوند؛ اطلاعات کاربران روی GitHub ارسال نمی‌شوند و بین دستگاه‌ها همگام نیستند. از تنظیمات، خروجی JSON بگیرید و در صورت نیاز بازیابی کنید. نسخه محلی قبلی و سایت آنلاین فضای ذخیره جداگانه دارند؛ برای انتقال اطلاعات از خروجی و بازیابی استفاده کنید.

## محدودیت‌ها
اتصال ایمیل، تلگرام، هوش مصنوعی، بکاپ خودکار، پرتال کاربران و محاسبات تخصصی مهندسی فعال نیستند. بانک امکانات برای برنامه‌ریزی است و به معنی پیاده‌سازی تمام ۴۰۷ مورد نیست.
